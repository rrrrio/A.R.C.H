# 管理审批记忆

长期记忆不是模型可自行写入或立即调用的功能。A.R.C.H. 会从一次完成的用户原话中保守提取候选，只有你在浏览器中批准后，它才会在后续对话中作为受限背景信息使用。

## 保存一个偏好

1. 在语音会话中清楚表达长期偏好，例如“我喜欢简洁回答”。
2. 等待本轮助手回答结束。候选提取在后台运行；成功写入后，“待确认记忆”会自动刷新。
3. 核对候选文字。可以编辑后保存、批准或拒绝。
4. 批准后继续同一会话或重新连接，再问“请用什么风格回答？”来验证该偏好是否影响回答。

不要通过“调取记忆”要求模型直接访问候选。待确认、拒绝和已删除内容不会进入模型上下文；这项限制防止未审核的转写错误或临时表述变成长期个人资料。

## 删除已批准记忆

在“已保存记忆”中选择“删除”。删除后的内容不会进入后续请求；页面刷新或重新登录后仍可确认它不再显示。

候选与已批准记忆仅保存在本机 SQLite 数据库。它们不上传到联网搜索、声音参考或浏览器数字人功能。
