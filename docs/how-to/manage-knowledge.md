# 管理本地知识库

本指南说明如何把本地资料纳入检索、确认索引完成，并移除不再需要的内容。完成标准是浏览器“本地知识库”状态显示索引文件数量，且删除源文件后重新索引不会继续保留其内容。

## 放入资料

将资料复制到：

    data/knowledge/inbox/

可递归放置普通文件。当前允许 `.txt`、`.md`、`.pdf`、`.py`、`.json`、`.yaml` 和 `.yml`，单个文件上限为 10 MiB。索引器跳过符号链接、目录、不支持的类型、损坏 PDF 和无法按 UTF-8 解码的文本文件。

不要放入密码、私钥、管理员凭据、令牌或任何不应作为模型上下文出现的内容。索引后的资料保存在本地 SQLite 数据库中，并可能被本地模型用于回答问题。

## 准备嵌入模型并建立索引

首次使用需下载固定版本的 BGE-M3：

    make rag-prepare

登录浏览器后，在导航中打开“知识库”，然后点击“建立索引”。该操作只扫描固定的 `data/knowledge/inbox/`，使用已准备好的本地模型更新索引；不会上传资料或执行浏览器提供的命令。操作完成后，页面会显示本次更新的文件数和新的索引状态。

终端仍可执行等价的离线索引：

    make rag-index

预期输出类似：

    Indexed 3 changed source(s).

`make rag-index` 强制离线，不会下载模型或读取 inbox 之外的文件。它依据文件内容 hash 更新 SQLite；没有修改时可以重复执行。

## 验证与删除

登录浏览器后查看“本地知识库”的文件数量和更新时间。“刷新状态”只重新读取这些已保存的状态，不会处理新增或修改的资料；修改 inbox 后请点击“建立索引”。建立语音会话后，可说“看一下周报”“看一下用户手册”或针对已放入资料的具体事实提问，例如“总结周报中的已完成事项”，并检查回答是否与该资料一致。命中本地资料时，“看一下”“阅读”和“概览”会返回简短摘要；助手会基于命中的片段作答，而不会声称无法查看本地资料。系统只把相关度足够的本地片段交给模型；命中这类片段的轮次不会调用本地终端或联网搜索工具。当前 UI 不提供原文浏览、索引或下载按钮。

删除资料时，从 `data/knowledge/inbox/` 删除源文件，再运行：

    make rag-index

索引器会清除对应条目。删除后的内容不应再被检索。若要重建整个数据库或恢复资料，请先按[备份和恢复本地数据](backup-and-restore.md)创建归档；恢复命令默认不会覆盖现有数据。
