# 使用浏览器数字人预览

浏览器数字人是可选的本地预览。启用后，A.R.C.H. 继续使用已有的 WebRTC 或 WebSocket 音频播放；数字人只在浏览器中观察已接收音频的能量，不会创建第二路声音。

## 启用预览

1. 登录 A.R.C.H.，在导航中打开“数字人”，然后在“浏览器数字人”区域启用预览。
2. 选择你有权使用的本地 `.vrm` 文件。
3. 连接语音并等待助手开始播报。具有 `aa` 元音表情的 VRM 会根据输出音频能量更新嘴部开合；没有模型时，页面显示中性本地占位模型。

所选 VRM 文件只在当前浏览器标签页的内存中加载。它不会上传到服务器、写入 `data/`、进入备份或出现在语音 profile 中。关闭预览、替换文件或刷新页面都会释放该模型。

## 当前边界

该预览要求支持 WebGL 的现代浏览器。模型没有 `aa` 元音表情时仍可显示，但不会获得当前的嘴部开合效果。它不传输表情、口型或视频帧到服务器，也不改变 Kokoro、Qwen 克隆、声音参考或浏览器音频的选择。模型文件自身的使用、再分发和人格化权限由模型的许可证和元数据决定，操作者必须自行确认。

当前实现已通过前端单元测试和生产构建，但尚未以真实 VRM、真实扬声器或目标设备测量初始化时间、帧率、音画偏移或插话停止时间。因此它是已实现但未设备验证的能力。
