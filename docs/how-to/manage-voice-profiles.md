# 管理本地声音参考

本指南管理本机 Qwen3-TTS 克隆运行时使用的本地声音参考。未连接语音时，保存或选择参考会在下一次
连接时生效；已在当前页面连接语音时，选择成功后页面会自动断开并重新连接以应用所选声音。声音相似度、
可听延迟和插话性能仍未完成设备验收。

## 添加参考

登录 A.R.C.H. 后，在“克隆声音参考”区域填写名称、参考音频的逐字文本，并选择一个音频文件。必须
勾选“我确认有权使用此参考声音”才能保存。

参考文件限制如下：

- 支持常见音频格式和多声道；后端使用 FFmpeg 读取第一条音轨。
- 时长不超过 10 秒，文件不超过 5 MiB。
- 必须提供与音频逐字一致的非空参考文本；后续 Qwen 克隆会把它作为 `ref_text`，不能随意填写。

选择文件后，文件名会继续显示在文件控件中，页面同时调用本机中文 Faster-Whisper 自动生成一份参考文本草稿并填入文本框；用户可以继续
编辑。保存前必须核对草稿，使它与音频逐字一致。自动转录只返回文本，不保存原始音频或草稿；若 ASR
模型尚未准备、没有检测到人声或转录失败，仍可手动填写文本。自动转录依赖 `make asr-prepare` 准备的
本地 ASR 模型。

页面只在提交前检查文件是否为空或超过 5 MiB；格式、音轨和时长由服务端最终检查。已经符合单声道、
16-bit PCM WAV 要求的文件可以直接保存；多声道或其他格式会转换为单声道、24 kHz、16-bit PCM WAV，
再写入 profile。常见的 WAV、MP3、FLAC、M4A/AAC、Ogg/Opus 和 WebM 都可以由当前主机的 FFmpeg
读取；不包含音轨、损坏或 FFmpeg 不支持的文件会被拒绝。要使用多声道或非 WAV，后端主机必须安装
`ffmpeg` 命令。

保存后，浏览器只显示名称、文本、规范化后的采样率和时长，不会显示服务器路径或返回原始音频。规范化
参考文件以 `reference.wav` 保存在受 Git 忽略的 `data/voices/profiles/`，不会进入当前数据库与知识资料备份归档。不要把参考文件、
浏览器导出、日志或截图发送给无关人员。

## 选择与删除

“选择克隆参考”会让下一次新建语音会话使用本机隔离的 Qwen worker。第一次使用 clone profile 时才加载
模型；同一页面因选择 profile 而自动断开并重新连接时，只重建媒体 pipeline，并复用仍在运行的本地模型
服务和 Qwen worker，不会为每次 profile 切换重复加载模型。已经在其他浏览器页面中运行的会话不会热切换，必须由该会话重新
连接。未运行 `make qwen-tts-prepare APPLY=1`、制品不完整或 worker 无法启动时，新会话会明确失败，绝不
静默改用 Kokoro。选择“使用 Kokoro 基线”会清除该选择并停止空闲 Qwen worker，但不会删除已保存参考。
删除会移除该 profile 的本地规范化 WAV 与元数据；若删除的是已选择 profile，系统自动恢复 Kokoro 选择。

新连接必须等后端发送 `voice_ready` 才会被视为可用。如果旧 WSS pipeline 尚未完成收尾，同一登录会话
的新连接会先等待旧 runner 释放再启动，不会把短暂的会话占用显示成可重复点击的连接失败；不同登录会话
仍保持单会话限制。

克隆语音在用户插话时会先停止当前 Qwen 生成以丢弃旧回答；下一轮会自动重新启动隔离 worker。这个硬停止
边界只发生在正在生成的请求被取消时，普通的空闲 profile 重连不会触发模型重载。若一次 worker 请求被拒绝
或没有返回 PCM，系统也会重启 worker 并只重试一次。Qwen 本地模型的首段音频可能需要
较长时间生成，克隆 TTS 会为首帧保留最多 30 秒的音频 context，避免长句被误判为无声。这样可以继续对话，
但恢复后的第一轮可能包含一次本地模型重载延迟。若重试仍失败，页面可能只有字幕；系统不会在克隆失败时
静默切回 Kokoro。

所有列出、保存、选择和删除请求都要求已登录会话、配置的 HTTPS Origin 和 CSRF token。未登录浏览器
无法读取 profile 元数据。不要依赖 profile 的存在来判断克隆可用；实际模型准备和验收状态见
[模型与许可证](../MODELS_AND_LICENSES.md)。

## 当前验收边界

自动化测试覆盖自动转录草稿、所有权确认、多声道 WAV 与 FLAC 转换、音频长度限制、符号链接存储拒绝、认证、CSRF、选择和删除回退。它们
不证明声音相似度、音色授权的法律充分性、模型下载、GPU 内存余量、可听首音、人工插话或第二台设备
体验。只有使用已获授权的参考在目标设备完成测量后，才能把克隆路径描述为已设备验证。
