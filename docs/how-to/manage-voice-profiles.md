# 管理本地声音参考

本指南管理用于后续 Qwen3-TTS 克隆运行时的本地声音参考。当前 A.R.C.H. 仍以 Kokoro 中文声线
播报；保存或选择参考不会切换当前语音，也不表示克隆运行时、可听延迟或插话性能已经验收。

## 添加参考

登录 A.R.C.H. 后，在“克隆声音参考”区域填写名称、参考音频的逐字文本，并选择一个 WAV 文件。必须
勾选“我确认有权使用此参考声音”才能保存。

参考文件限制如下：

- 单声道、16-bit PCM WAV。
- 采样率在 8 kHz 到 48 kHz 之间。
- 时长不超过 10 秒，文件不超过 5 MiB。
- 必须提供非空参考文本；它会在后续克隆时避免额外转录步骤。

保存后，浏览器只显示名称、文本、采样率和时长，不会显示服务器路径或返回原始音频。参考文件保存在
受 Git 忽略的 `data/voices/profiles/`，不会进入当前数据库与知识资料备份归档。不要把参考文件、
浏览器导出、日志或截图发送给无关人员。

## 选择与删除

“选择克隆参考”会让下一次新建语音会话请求本机隔离的 Qwen worker；当前已经连接的会话不改变。
未运行 `make qwen-tts-prepare APPLY=1`、制品不完整或 worker 无法启动时，新会话会明确失败，绝不静默改用 Kokoro。选择“使用 Kokoro 基线”会清除该选择，但不会删除已保存参考。
删除会移除该 profile 的本地 WAV 与元数据；若删除的是已选择 profile，系统自动恢复 Kokoro 选择。

所有列出、保存、选择和删除请求都要求已登录会话、配置的 HTTPS Origin 和 CSRF token。未登录浏览器
无法读取 profile 元数据。不要依赖 profile 的存在来判断克隆可用；实际模型准备和验收状态见
[模型与许可证](../MODELS_AND_LICENSES.md)。

## 当前验收边界

自动化测试覆盖所有权确认、WAV 格式/长度限制、符号链接存储拒绝、认证、CSRF、选择和删除回退。它们
不证明声音相似度、音色授权的法律充分性、模型下载、GPU 内存余量、可听首音、人工插话或第二台设备
体验。只有使用已获授权的参考在目标设备完成测量后，才能把克隆路径描述为已设备验证。
